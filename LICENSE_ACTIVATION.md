# 📖 PANDUAN AKTIVASI LISENSI PELANGGAN (LICENSE_ACTIVATION.md)
**Petunjuk Aktivasi Sistem Presensi Digital untuk Sekolah & Instansi**

---

## 1. CARA MENGAKTIFKAN LISENSI APLIKASI
1. Buka aplikasi Presensi Digital pada browser browser sekolah Anda.
2. Masuk sebagai **Admin / Operator Sekolah**.
3. Klik tombol **"Aktivasi Lisensi"** pada banner bagian atas atau buka menu **Pengaturan** $\rightarrow$ **Lisensi Aplikasi**.
4. Masukkan **20 Digit Kunci Lisensi** resmi yang Anda terima dari Administrator (Format: `XXXX-XXXX-XXXX-XXXX-XXXX`).
5. Klik tombol **[ AKTIFKAN SEKARANG ]**.
6. Tunggu beberapa detik hingga proses verifikasi selesai.
7. Setelah berhasil, aplikasi akan otomatis beralih ke **FULL VERSION**.

---

## 2. PENJELASAN PESAN ERROR KETIKA AKTIVASI GAGAL

| Pesan Error | Penyebab | Solusi |
| :--- | :--- | :--- |
| **"License key is invalid"** | Format kunci salah atau ada karakter yang keliru ketik | Periksa kembali 20 karakter kunci lisensi Anda |
| **"License is already bound to another domain"** | Kunci lisensi sudah terdaftar dan terkunci pada domain/website sekolah lain | Hubungi Admin Pusat jika Anda melakukan migrasi domain |
| **"License has expired"** | Masa berlaku lisensi telah berakhir | Hubungi Admin Pusat untuk melakukan perpanjangan lisensi (*Renewal*) |
| **"License is currently suspended"** | Lisensi dinonaktifkan sementara oleh pengelola | Hubungi layanan bantuan Administrator Pusat |
| **"License has been revoked"** | Lisensi telah dibatalkan secara permanen | Ajukan lisensi baru ke Administrator Pusat |
| **"Server License sedang offline"** | Koneksi jaringan terputus atau server sedang pemeliharaan | Pastikan perangkat Anda terhubung ke internet dan coba kembali beberapa saat lagi |

## 3. PERIKSA STATUS & MASA BERLAKU LISENSI
Anda dapat melihat detail lisensi Anda kapan saja melalui menu **Status Lisensi**:
- **Nama Sekolah**: Sesuai data pendaftaran resmi.
- **Domain Terikat**: Domain web yang berhak menggunakan sistem.
- **Paket Fitur**: `BASIC`, `PRO`, atau `ENTERPRISE`.
- **Masa Berlaku**: Tanggal kedaluwarsa atau *Lifetime*.
